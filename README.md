# 卓球戦績メモ

卓球の試合結果を記録するWebアプリです。ビルド不要の静的サイトで、データはブラウザ（localStorage）に保存されます。

## 機能

- **セット数のみ（デフォルト）**: 相手・日付・試合形式（3/5/7ゲームマッチ）を入れて、`3-1` などの結果ボタンを押すだけで記録できます。
- **詳細モード（1点ごと）**: 記録画面で「詳細」に切り替えると、試合中に1点ずつ入力するスコアボードになります。
  - 11点先取・2点差のジュースを自動判定し、ゲーム/試合の終了を検出
  - サーブ権（2本交代、10-10以降は1本交代、ゲームごとに先サーブ交代）を表示
  - ゲームポイント・マッチポイントの表示、1点戻す、サーブ順の修正
  - 途中でページを閉じても試合は保存され、続きから再開できます
  - 試合後はゲームスコア、サーブ時/レシーブ時の得点率、最大連続得点、得点の流れを表示
- **対戦相手の候補**: 過去に記録した相手を対戦回数順にボタンで表示。入力するとひらがな/カタカナを区別せず絞り込み
- **友だち連携**: 「友だち」タブのQRコードかリンクを対戦相手に開いてもらうと、お互いが友だちに追加される（最初の1回だけ）
  - 以降、友だちとの試合を保存すると相手のアプリにも結果が自動で届く（相手側では勝敗・スコアが反転して記録される）
  - 両方が同じ試合を記録した場合は1試合としてまとめる。自分の記録を削除・修正すると相手側にも反映
  - 記録本体は各端末に保存。受け渡しには無料の中継サービス [ntfy.sh](https://ntfy.sh) を経由する（最大12時間預かり。相手から受け取りの返事が来るまで、アプリを開くたびに再送）
  - メモは送らない。IDを知っている人は結果を送れるので、リンクは対戦相手にだけ渡す
- **履歴**: 月ごとの一覧、検索、編集・削除
- **成績**: 勝率、ゲーム取得率、直近の勝敗、対戦相手別・大会別の成績（期間で絞り込み可）
- **設定**: 自分の名前、JSONでのエクスポート/インポート

## 使い方

```sh
npm start        # http://localhost:8000 で起動（python3 の簡易サーバー）
npm test         # スコア計算ロジックのテスト
```

`index.html` をそのまま開いても動きます。

## GitHub Pages で公開

`main` に push すると、GitHub Actions（`.github/workflows/pages.yml`）がテストを実行してから GitHub Pages にデプロイします。

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
公開URLは `https://<ユーザー名>.github.io/tt_record/` です。スマホで開いて「ホーム画面に追加」するとアプリのように使えます。

記録はブラウザごとに保存されるため、端末を変えるときは設定画面のエクスポート/インポートを使ってください。

## 構成

- `index.html` / `css/style.css` — 画面
- `js/scoring.js` — スコア計算（ゲーム判定・サーブ順・集計）。DOMに依存しない純粋関数
- `js/link.js` — 友だち連携のメッセージ形式・検証・相手視点への変換。DOMに依存しない純粋関数
- `js/vendor/qrcode.js` — QRコード生成（[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)、MIT）
- `js/app.js` — 画面描画と操作、データ保存
- `tests/` — `node --test` で動くテスト
