# 卓球戦績メモ

卓球の試合結果をスマホでかんたんに記録して、勝率や対戦成績を見られるアプリです。

アプリ: https://tomochi3.github.io/tt_record/

この説明は3部に分かれています。

1. [かんたん説明](#1-かんたん説明) — まずはここだけ読めば使えます
2. [くわしい説明](#2-くわしい説明) — 機能ごとの使い方
3. [セキュリティ](#3-セキュリティ) — 暗号化・改ざん検知・公開してはいけないもの など

---

## 1. かんたん説明

### どんなアプリ？

- 試合の結果を **ボタン1つ** で記録できます（`3-1` を押して保存するだけ）。
- 試合中に **1点ずつ** つけることもできます。サーブの順番も自動で表示します。
- 勝率や相手ごとの成績が **自動で集計** されます。
- 対戦相手と **友だちになる** と、どちらかが記録するだけで相手にも結果が届きます。
- 「負けたら奢り」の約束も **何奢りたまっているか** を数えてくれます。

### はじめかた

1. スマホで上のリンクを開き、「ホーム画面に追加」します。
2. 「設定」タブで自分の名前を入れます。
3. 「記録」タブで相手の名前を入れ、結果のボタンを押して「保存」。これだけです。

### 画面の見かた

| タブ | できること |
| --- | --- |
| 📊 戦績 | 成績と試合の一覧。相手の名前をタップすると、その人との成績 |
| ＋ 記録 | 試合を記録する（ふつう / 1点ごと） |
| 🤝 友だち | 対戦相手と友だちになる |
| ⚙ 設定 | 名前・画面の明るさ・バックアップ |

### 覚えておくこと

- 記録はそのスマホの中に保存されます。**機種変更の前は「設定」→「エクスポート」** でファイルに保存してください。
- 消したり間違えたりしても、直後に出る「元に戻す」で取り消せます。

## 2. くわしい説明

### 試合を記録する（記録タブ）

1. 対戦相手を入力します。入力欄の下に過去の相手や友だちがボタンで出るので、タップすれば入力できます（対戦回数の多い順。ひらがな/カタカナを区別せずに絞り込めます）。
2. 試合形式（3 / 5 / 7ゲームマッチ）を選び、`3-1` や `2-3` などの結果ボタンを押して「保存」します。保存ボタンは画面の下に固定されているので、スクロールせずに押せます。
3. 日付・大会・練習名・メモは下の「そのほか（任意）」に入れます（日付は今日が入っています）。

### 1点ごとに記録する（詳細モード）

1. 記録画面で「詳細（1点ごと）」に切り替え、最初のサーブを選んで「試合開始」。
2. 点を取った側の色（青＝自分、赤＝相手）をタップします。
3. 11点先取・2点差のジュースを自動で判定し、次のゲームにも自動で進みます。
4. サーブ（2本交代、10-10以降は1本交代、ゲームごとに先サーブ交代）・ゲームポイント・マッチポイントを表示します。
5. 押し間違えたら「1点戻す」、最初のサーブが逆だったら「先サーブを入替」。
6. 試合中はタブバーを隠してスコアボードを画面いっぱいに表示します。スマホを横向きにしても、点数とボタンが1画面に収まります。
7. 途中でアプリを閉じても続きから再開できます（「一時中断」したときも、戦績タブの赤い帯から）。
8. 試合が終わったら、必要ならメモを書いて「記録を保存」。試合ページで各ゲームのスコア、サーブ時/レシーブ時の得点率、最大連続得点、得点の流れが見られます。

試合中は画面が自動で消えないようにしています（Chrome・Edge・Safari 16.4 以降など、対応しているブラウザのみ）。

### 得点板（試合中）

スマホを台の横に置いて、両方の選手に点数を見せるための表示です。

1. 試合中の画面で「📺 得点板にする」を押すと、点数を大きく表示する得点板に切り替わります（対応ブラウザでは全画面になります）。横向きに置くといちばん大きく表示されます。
2. 台の左側にいる選手の点数が左、右側にいる選手の点数が右に出ます。点を取った選手の側をタップします。
3. 名前の横の四角い数字は、取ったゲーム数です。サーブ・ゲームポイント・マッチポイントも表示されます。
4. ゲームが終わるたび、そして最終ゲームでどちらかが5点に達したときに「チェンジエンド」と表示し、左右を自動で入れ替えます。
5. 最初に左右が逆だったときは「⇄ 左右を入替」を押します。押し間違えたら「↶ 1点戻す」（チェンジエンドも元に戻ります）。
6. 「✕ 閉じる」でいつもの表示に戻ります。得点板で使ったかどうかは覚えていて、次の試合も同じ表示で始まります。

### 成績を見る（戦績タブ）

成績と試合の一覧を1ページでまとめて表示します。上の期間（全期間 / 今年 / 直近90日 / 直近30日）で、ページ全体を絞り込めます。

- **成績**: 勝敗、勝率、ゲーム取得率、フルゲーム（最終ゲームまでもつれた試合）の勝敗、奢りの状況。1点ごとに記録した試合があれば、サーブ時/レシーブ時の得点率なども出ます。
- **対戦相手別**: 最近対戦した相手から順に、勝率・勝敗・最終対戦日が並びます（右上で対戦数順・勝率順・名前順に切り替え）。最初は5人まで表示し、「ほか○人を表示」で全員を出せます。大会・練習別の成績もあります。
- **試合**: ページの下に月ごとの一覧と検索があります。試合をタップすると詳細の確認・編集・削除ができます。
- **相手ごとの成績**: 「対戦相手別」の行、試合ページの「vs 〇〇」、友だち一覧の名前をタップすると、その相手との勝率・ゲーム取得率・連勝/連敗・直近の流れ・対戦履歴が見られます。
- 試合の削除・試合の破棄・友だちの解除は確認画面を出さずにすぐ行い、直後のポップアップの「元に戻す」で取り消せます。

### 友だちと連携する（友だちタブ）

対戦相手を友だちに追加しておくと、どちらかが試合を記録するだけで、相手のアプリにも結果が届きます。追加は相手ごとに最初の1回だけです。

追加のしかたは3通りあります。

- **QRコード**: 自分のQRコードを相手のスマホのカメラで読み取ってもらい、「追加する」を押してもらう。
- **リンク**: 「リンクをコピー」または「共有…」で相手に送り、開いて「追加する」を押してもらう。
- **友だちコード**: 相手の「友だちコードをコピー」で送ってもらい、「友だちを追加」の欄に貼り付けて「追加」。名前は相手が承認したときに、相手が設定した名前で自動的に表示されます。

どの方法でも、追加すると相手の画面の上部に「〇〇さんから友だち申請」が表示されます。相手が「追加」を押すと連携完了です（「×」で断ると、その人からの申請は以後表示されません）。申請中に送った結果は相手のアプリで預かられ、追加された時点で反映されます。

連携後は次のように動きます。

- 友だちとの試合を保存すると、相手が次にアプリを開いたときに結果が届きます（相手側では勝敗とスコアが反転して記録されます）。逆も同じです。
- 2人とも同じ試合を記録した場合は、1試合にまとめられます。
- 自分の記録を修正・削除すると、相手側にも反映されます。友だちが過去の試合を直したり消したりしたときは、すぐ反映したうえで「結果 2-3 → 3-2」のように知らせます。
- 相手ごとの成績ページの「📒 帳簿」に、その友だちとのやり取りの履歴（誰が・いつ・何をしたか）が出ます。
- 友だちの名前は、相手が自分で設定した名前で表示されます。相手が名前を変えると、あなたの画面の表示名と過去の試合の相手名も自動で変わります。
- 友だち一覧の「名前」ボタンで、あなたの画面にだけ表示される呼び名に変えられます（相手には伝わりません）。呼び名を付けている間は相手が名前を変えても呼び名のままで、一覧に「本人の名前」が併記されます。空欄にすると相手が設定した名前に戻ります。
- 試合ページの「🔗」の行で、相手に届いたか（送信待ちか）、相手が記録した試合かが分かります。
- 「今すぐ同期」ですぐに確認できます。アプリを開いたときと、開いている間は1分ごとに自動で確認します。
- メモは自分用で、相手には届きません。

届くまでのしくみ:

- 結果の受け渡しには無料の中継サービス [ntfy.sh](https://ntfy.sh) を使います。記録本体は各端末にだけ保存されます。
- ntfy.sh の預かりは12時間ですが、同じ内容を「11時間後〜66時間後に配達」の予約でも預けるので、相手が約3日アプリを開かなくても届きます。
- それでも相手から受け取りの返事が来なければ、あなたがアプリを開いたときに自動で再送します（3日以上たってから届けたいときは、送った側がアプリを開いてください）。

iPhoneでホーム画面に追加したアプリは、Safariとデータが別になります。カメラでQRコードを読んでSafariで開いた場合は、そのリンクをアプリの「友だち」タブの「友だちを追加」に貼り付けてください。

### 奢りメモ

「負けた方が勝った方に奢る」約束をしたときに使います。設定は不要で、試合ごとに選べます。

1. 試合を記録するとき、「奢り（何勝で1奢り？）」で なし / 1勝 / 2勝 / 3勝 を選びます。同じ相手との次の試合では、前回と同じものが最初から選ばれています。詳細モードの試合でも選べます。
2. 「N勝で1奢り」の試合は、勝つと相手から 1/N 奢り、負けると相手へ 1/N 奢りがたまります（例: 2勝で1奢りなら1試合 0.5奢り）。
3. たまった奢りは「あなた → 山田さん 1.5奢り」「山田さん → あなた 1奢り」のように、相手ごとに表示されます（保存したときの知らせ、戦績タブ、相手ごとの成績ページ）。
4. 奢ったら、相手ごとの成績ページで「💸 1奢りした」、奢ってもらったら「🍜 1奢ってもらった」を押すと、1奢り分が差し引かれます。押した直後のポップアップ（5秒間）の「元に戻す」で取り消せます。
5. お互いに奢りが残っているときは「⇄ ○奢りずつ相殺」で、少ない方の量だけ両方から差し引けます。
   - 連携中の友だちの場合は「相殺を提案」になり、相手が「合意する」を押したときに両方の端末で相殺されます（相手は「断る」もできます）。
   - 連携していない相手の場合は、相手と話して合意してから押してください。

- 連携中の友だちとの試合は「何勝で1奢り」も相手に届くので、相手の画面でも同じように数えられます。
- 「奢った/奢ってもらった」の記録も相手に届き、相手の画面の残りにも反映されます。2人が同じ1回をそれぞれ記録しても（同期の前に両方が押しても）、2日以内の同じ量の記録は1回分として数えます。
- 以前の「先に○勝した方が奢り・未/済」のメモは、「済」にしたものが「奢った/奢ってもらった」の記録に移ります。

### 設定タブ

- **名前**: 友だちのアプリにはこの名前で表示されます（まだ名前がないときは「友だち」タブの一番上でも入れられます）。
- **画面の明るさ**: 自動 / ライト / ダーク。
- **データ**: この端末の保存状態の表示と、エクスポート / インポート。

### バックアップ・機種変更

記録はそのスマホのブラウザの中にだけ保存されます。アプリは起動時に、ブラウザへ「保存データを自動で消さない」よう頼みます（Chrome・Edge・Safari。確認画面は出ません）。iPhone の Safari では7日間開かないと消えることがあるため、ホーム画面に追加して使ってください。

機種変更の前に、設定タブの「エクスポート」でファイルに保存し、新しいスマホで「インポート」してください（試合・メモ・友だち一覧・奢りの記録が入ります）。

### 開発者向け

```sh
npm start        # http://localhost:8000 で起動（python3 の簡易サーバー）
npm test         # テスト
```

ビルド不要の静的サイトです。`index.html` をそのまま開いても動きます。

`main` に push すると、GitHub Actions（`.github/workflows/pages.yml`）がテストを実行してから GitHub Pages にデプロイします。初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。公開URLは `https://<ユーザー名>.github.io/tt_record/` です。

ファイル構成:

- `index.html` / `css/style.css` — 画面
- `js/app.js` — 画面描画と操作、データ保存
- `js/scoring.js` — スコア計算（ゲーム判定・サーブ順・集計）。DOMに依存しない純粋関数
- `js/treat.js` — 奢りメモの集計（1勝ごとに 1/N 奢り、奢った記録・相殺の差し引き）。DOMに依存しない純粋関数
- `js/link.js` — 友だち連携のメッセージ形式・相手視点への変換・保存データの検証
- `js/ledger.js` — 帳簿（[3. セキュリティ](#帳簿改ざんを検知できる記録)を参照）
- `verify.html` / `js/verify.js` — 確認ページ（[3. セキュリティ](#証拠ファイルと確認ページ)を参照）
- `js/theme.js` — 画面表示前にテーマを反映
- `js/vendor/qrcode.js` — QRコード生成（[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)、MIT）
- `tests/` — `node --test` で動くテスト

## 3. セキュリティ

### 友だち連携の暗号化

- やり取りの中身は、端末ごとに作られる鍵で暗号化します（Web Crypto: ECDH P-256 + AES-GCM）。中継サービス（ntfy.sh）や第三者には中身が読めず、友だちになりすました送信や改ざんされた内容は受け付けません。
- 友だち申請の名前だけは、暗号化の前に送られます。
- 知らない人からの申請は「追加」を押さない限り友だちになりません。すでにいる友だちと同じ名前の申請には「別の人です」と注意が出ます。
- 受け取った名前からは見えない文字や文字の向きを変える制御文字を取り除き、既存の友だちと見分けがつかない名前を作れないようにしています。壊れた公開鍵の友だち申請は表示しません。
- 英数字20文字だけのIDや、暗号化対応前の古いリンクでは友だちを追加できません。

### 帳簿（改ざんを検知できる記録）

連携中の友だちとのやり取りは、ブロックチェーンの考え方のうち「改ざんされたら必ず分かる」部分だけを使った帳簿に残ります。操作は増えません。

- **追記だけ**: 試合の記録・変更・削除、奢った記録、相殺は、上書きせずに帳簿の新しい行として足します。各行には通し番号と前の行のハッシュが入ります。
- **署名**: 各行は端末ごとの署名用の鍵（ECDSA P-256・取り出し不可）で署名します。1行目は署名用の公開鍵です。
- **写しを持ち合う**: 自分の帳簿の写しは相手の端末に、相手の帳簿の写しは自分の端末に残ります。受け取った側は「どこまで受け取ったか（番号とハッシュ）」に署名した受領証を返事に入れるので、両方の端末で照らし合わせられ、「受け取っていない」とはあとから言えません。

相手の成績ページの「📒 帳簿」で、照合の結果（「○行目まで写しと一致・署名つきの受領証あり」など）を確認できます。次のようなときは警告を出し、戦績タブの上にも帯を出します（「確認した」で消えます）。

- 相手の帳簿の同じ番号に、前に届いたのと違う内容が届いた（あとから書き換えた証拠として、署名つきの2つの行を保存します）
- 前の行とつながらない行や、署名が正しくない行が届いた（反映しません）
- 相手の端末にある自分の帳簿の写しが、自分の帳簿と食い違っている
- 相手が帳簿をはじめから作り直した（友だちの登録し直しなど。以前の行は残します）

### 証拠ファイルと確認ページ

書き換えや食い違いを署名つきで示せるとき（同じ番号に違う内容・前の行とつながらない行・署名つきの受領証との食い違い）は、帳簿の「署名つきの証拠」に「証拠ファイルを保存」が出ます（「確認した」のあとも残ります）。

保存した .json を [確認ページ](https://tomochi3.github.io/tt_record/verify.html)（`verify.html`）に入れると、アプリを入れていない第三者でも、どの鍵が何を署名したかを確かめられます。ファイルは端末の中だけで確かめ、どこにも送りません（確認ページは通信を一切しない設定です）。鍵は「指紋」（例 `yamz-ELBt-TvM8-qlIP`）で表示され、帳簿の下に出る「鍵の指紋」と見比べられます。

### ビットコインへの刻印（設定タブ・初期はオフ）

オンにすると、すべての帳簿の「最後の番号と先頭のハッシュ」をまとめた元データのハッシュ値を、1日1回まで OpenTimestamps の刻印サーバー（2か所）に送ります。数時間後にビットコインのブロックに入り、「その日時に帳簿がその状態だった」ことを誰もあとから覆せなくなります。費用はかからず、記録の中身は送りません。

設定タブの「証明ファイル（.ots）」と「元データ（.json）」を [opentimestamps.org](https://opentimestamps.org) の Verify に入れると確認できます。元データにはこの端末の署名が入っていて、確認ページで「誰が刻んだか」も確かめられます。

### 公開しないでほしいもの

不特定多数に公開しないほうがよいものには、アプリ内に「🔒 公開しないで」と表示しています。

- 友だちリンク・QRコード・友だちコード（あなたのIDと公開鍵が入っていて、誰でも友だち申請を送れるようになるため。対戦相手にだけ渡してください）
- エクスポートしたファイル（試合の記録・メモ・友だちの一覧が入っているため）
- 刻印の元データ（.json）（あなたと友だちのIDが入っているため。証明ファイル（.ots）は公開しても大丈夫です）
- 証拠ファイル（あなたと友だちのIDと記録が入っているため。話し合いに必要な人にだけ見せてください）

### アプリ全体の対策

- `index.html` の Content-Security-Policy で、同じサイト以外のスクリプトの実行と、ntfy.sh・OpenTimestamps の刻印サーバー以外への通信を禁止しています（`innerHTML` を使うため、万一の混入対策）。刻印サーバーへは設定でオンにしたときだけ通信します。
- インポートしたファイルや端末の保存データは、読み込むたびに1件ずつ検証してから使います。
- 他のサイトに埋め込まれた状態では画面を出しません（透明に重ねてボタンを押させる攻撃の対策）。
- 同じ端末で複数のタブを開いていても、他のタブで保存した内容を読み込み直すので記録は上書きされません。
- 暗号用・署名用の秘密鍵は、ブラウザの中で使えるだけで中身を読み出せない「取り出し不可」の鍵として IndexedDB に保存しています。エクスポートしたファイルにも鍵やIDは含まれません（帳簿もエクスポートには含めません）。
- デプロイに使う GitHub Actions は、タグではなくコミットのハッシュで固定しています（タグが書き換えられても別のコードが動かないように）。更新するときは新しいリリースのハッシュに置き換えます。
- `tomochi3.github.io` 配下の他の GitHub Pages サイトとはブラウザの保存領域が共有されます。このアカウントで信頼できないコードを含むサイトを公開しないでください（独自ドメインにすると分離できます）。

### よくある疑問

#### Q. 帳簿の記録はどこに保存されているの？

**2人それぞれのスマホの中**（ブラウザの保存領域）です。サーバーやブロックチェーンには保存しません。

| | あなたのスマホ | 友だちのスマホ |
| --- | --- | --- |
| あなたが書いた帳簿 | 原本 | 写し |
| 友だちが書いた帳簿 | 写し | 原本 |

同じ帳簿が必ず2台にあり、どちらか1台だけを書き換えても、もう1台と合わなくなります。中継サービス（ntfy.sh）は、暗号化された行を相手に届けるまで（最長で約3日）預かるだけで、帳簿は持ちません。

#### Q. ブラウザの保存容量はどれくらい？

1つのサイト（このアプリでは `tomochi3.github.io`）につき、**約5MB** が目安です（Chrome・Safari・Firefox など。ブラウザによって多少違います）。試合の記録・友だち一覧・帳簿は、すべてこの中に入ります。帳簿の行は小さいので、ふつうの使い方なら何年分も入ります。

- 署名用・暗号用の鍵は別の保存領域（IndexedDB）に入れていて、大きさはごくわずかです。
- この約5MBは、`tomochi3.github.io` 配下の他の GitHub Pages サイトと共有です。
- 保存容量がいっぱいになると「保存に失敗しました」と表示され、新しい記録を保存できなくなります。ときどきエクスポートで記録をファイルに残しておくと安心です。

#### Q. 「ハッシュ」と「署名」って何？

- **ハッシュ**: 文章から計算する43文字の「指紋」のような値です。文章が1文字でも変わるとまったく別の値になり、ハッシュから元の文章は分かりません。各行に前の行のハッシュを入れているので、途中の1行を変えると、そのあとの行とつながらなくなります。
- **署名**: その端末だけが持つ鍵で作る「はんこ」です。誰でも1行目の公開鍵で本物か確かめられますが、鍵を持っている端末以外には作れません。内容を変えると署名が合わなくなります。

#### Q. 中央のサーバーがないのに、どうやって改ざんが分かるの？

相手のスマホにある写しと照らし合わせます。

- あなたが自分の帳簿の過去の行を書き換えると、次に送る行の「前の行のハッシュ」が友だちの写しと合わず、友だちのスマホに警告が出ます。
- 同じ番号の行を書き直して送ると、友だちのスマホには「同じ番号に違う内容」が署名つきで2つそろい、そのまま証拠になります。
- 友だちから届く署名つきの受領証（「何行目まで、このハッシュで受け取った」）とも合わなくなるので、あなたのスマホにも警告が出ます。

#### Q. ハッシュ値はどこに保存されているの？

帳簿と同じく、**2人それぞれのスマホの中**です。

- **各行のハッシュ**: 帳簿の1行ごとに、その行のハッシュを行と一緒に保存しています（自分の帳簿・相手の帳簿の写しの両方）。
- **前の行のハッシュ**: 各行の中身に書き込まれていて、署名の対象にも含まれます。あとから差し替えると署名が合わなくなります。
- **受領証**: 友だちから届いた最新の受領証（「何行目まで、このハッシュで受け取った」と友だちが署名したもの）を保存しています。
- **刻印の元データ**: 刻印をオンにしている場合は、刻んだときの各帳簿の「最後の番号と先頭のハッシュ」を、直近30回分スマホに保存しています。その元データのハッシュは、刻印サーバーを通してビットコインのブロックにも入ります。

ハッシュは行の中身から誰でも計算し直せます。アプリは行を受け取るたびに中身から計算し直して、すでにある行や「前の行のハッシュ」と比べています（確認ページも同じように計算し直します）。

#### Q. 相手のスマホにある「写し」のほうを書き換えたら？

写しの各行には書いた人の署名がついていて、署名は書いた人の端末にしか作れません。写しを書き換えると署名が合わなくなるので、証拠としては使えません（確認ページでも通りません）。書いた本人のスマホの原本はそのままです。

#### Q. 2人で示し合わせて書き換えたら？

防げません。2人がそろって帳簿を作り直せば、食い違いは残らないからです。この帳簿は「どちらか一方だけが勝手に変えた」ことを見つけるためのものです。

ビットコインへの刻印をオンにしていれば、刻印した時点の帳簿の状態（ハッシュ）はあとから変えられません。刻印の元データ（.json）と証明ファイル（.ots）を第三者が持っていれば、刻印のあとで帳簿が作り直されたことを示せます。

#### Q. 2人で示し合わせて書き換えたら、削除した記録は残る？

アプリの操作だけなら残ります。ただし、2人がそろってブラウザのデータを消せば残りません。

- **試合の削除・修正**: アプリで試合を消したり直したりしても、元の行は消さずに「取り消し」「変更」の行を足すだけです。元の記録は帳簿に残ります。
- **友だちの解除と登録し直し**: 解除した側のスマホからは、その友だちとの帳簿が消えます。相手のスマホには以前の帳簿が残ります（3回分まで）。
- **ブラウザのデータを消す・直接書き換える**: 2人ともがそうすれば、その記録はどこにも残りません。

刻印をオンにしていれば、刻んだ時点の帳簿のハッシュはビットコインに残ります。ただし、ハッシュから消した記録の中身は分かりません。中身まで残したいときは、証拠ファイルや刻印の元データ（.json）を、2人以外の人に渡しておく必要があります。

#### Q. ブロックチェーンに試合の記録が載るの？

載りません。刻印をオンにしたときだけ、帳簿の状態を表すハッシュ値（32バイト）を送ります。ハッシュから試合の中身や名前は分かりません。オフ（初期設定）なら何も送りません。

#### Q. 中継サービス（ntfy.sh）は帳簿を読んだり書き換えたりできる？

できません。行は暗号化して送るので読めず、書き換えると暗号の検証と署名の確認で受け付けません。中継サービスにできるのは「届けない（捨てる・遅らせる）」ことだけです。

その場合は受領証が返ってこないので、アプリが自動で送り直します。途中の行だけが届かないときは、あとの行を「前の行の到着待ち」として預かり（帳簿に表示されます）、前の行が届いた時点で順番どおりに反映します。

#### Q. 受け取った側が「そんな記録は届いていない」と言ったら？

受け取った側の端末は、受け取るたびに「何行目まで、このハッシュで受け取った」に署名した受領証を返します。帳簿に「署名つきの受領証あり」と出ていれば、その行まで相手の端末に届いたことを相手自身の署名で示せます。

#### Q. 友だちの公開鍵が本物だと、どうして分かるの？

帳簿の1行目（公開鍵）は、友だち追加のときに交換した暗号の鍵で暗号化して届くので、途中ですり替えることはできません。

- 友だちのQRコードやリンクを開いた側は、相手の鍵を直接受け取っています。
- 申請を受けた側は、届いた申請の鍵を使います。知らない人からの申請を承認しないかぎり、別人の鍵にはなりません（同じ名前の申請には「別の人です」と注意が出ます）。

確実にしたいときは、相手ごとの成績ページの帳簿の下にある「鍵の指紋」を、相手の画面と見比べてください。

#### Q. 友達の公開鍵はどこに保存され、いつ照合しているの？

友だちの鍵は2つあり、どちらも**あなたのスマホの中**（ブラウザの保存領域）に保存しています。

| 鍵 | 受け取るとき | 使うとき |
| --- | --- | --- |
| 暗号用の公開鍵 | 友だち追加のとき（QRコード・リンク・友だちコード、または届いた申請） | 友だちに送る内容の暗号化と、届いた内容の復号のたび。復号できないもの・改ざんされたものは受け付けません |
| 署名用の公開鍵 | 友だちの帳簿の1行目が届いたとき（その鍵自身の署名を確かめてから保存） | 友だちの帳簿の行が届くたび、受領証が届くたび。署名が合わない行は反映しません |

- 帳簿の1行目がもう一度、別の鍵で届いた場合は「帳簿をはじめから作り直しました」と知らせます。以前の行は残し、新しい鍵で確かめ直します。
- 確認ページでは、証拠ファイルに入っている1行目（公開鍵）を使って、その場で照合します。
- 帳簿の下の「鍵の指紋」は、保存している署名用の公開鍵から計算して表示しています。

#### Q. 署名用の鍵を盗まれることはない？

鍵は「取り出し不可」の形でブラウザに保存していて、署名に使えるだけで中身は読み出せません。アプリ自身も読めないので、ファイルにコピーしたり外に送ったりはできません。

#### Q. 機種変更したり、データが消えたりしたら帳簿はどうなる？

- 帳簿と鍵はエクスポートに含めないので、新しいスマホには引き継がれません。新しいスマホでは鍵も新しくなり、帳簿は1行目から始まります。それまでの帳簿は、友だちのスマホに写しとして残ります。
- 古いデータに戻した（巻き戻した）場合は、友だちの受領証の行数のほうが多くなるので「データが消えたか巻き戻された可能性」と警告が出ます。

#### Q. 行を消さないなら、帳簿はどんどん大きくならない？

増え続けますが、1行はおおむね数百バイトです（1点ごとの記録つきの試合でも約2.5KBまで。それより大きい試合は、帳簿には結果だけを載せます）。ふつうの使い方なら、千試合単位で入る大きさです

#### Q. 台帳のデータはどこに保存されている？

スマホのブラウザの中の、このアプリ専用の保存領域です。

- **帳簿の中身**（自分の帳簿・友だちの帳簿の写し・受領証・警告・証拠・刻印の記録）は、試合の記録と同じ場所（localStorage の `ttrecord.v1`）に、まとめて保存しています。
- **署名用・暗号用の秘密鍵**は、別の場所（IndexedDB）に「取り出し不可」の形で保存しています。
- サーバー・中継サービス・ブロックチェーンには保存しません。
- エクスポートしたファイルには含まれません。
- ブラウザの「サイトのデータを削除」をすると、帳簿も鍵も消えます。友だちのスマホにある写しは残ります。
