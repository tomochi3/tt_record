# 卓球戦績メモ

卓球の試合結果を記録するWebアプリです。ビルド不要の静的サイトで、データはブラウザ（localStorage）に保存されます。

## 機能

- **セット数のみ（デフォルト）**: 相手・日付・試合形式（3/5/7ゲームマッチ）を入れて、`3-1` などの結果ボタンを押すだけで記録できます。
- **詳細モード（1点ごと）**: 記録画面で「詳細」に切り替えると、試合中に1点ずつ入力するスコアボードになります。
  - 11点先取・2点差のジュースを自動判定し、ゲーム/試合の終了を検出
  - サーブ権（2本交代、10-10以降は1本交代、ゲームごとに先サーブ交代）を表示
  - ゲームポイント・マッチポイントの表示、1点戻す、サーブ順の修正
  - 途中でページを閉じても試合は保存され、続きから再開できます
  - **得点板**: 台の横に置いて両方の選手に見せる大きな表示。チェンジエンドに合わせて左右を自動で入れ替え
  - 試合中は画面が自動で消えないようにします（対応ブラウザ）
  - 試合後はゲームスコア、サーブ時/レシーブ時の得点率、最大連続得点、得点の流れを表示
- **対戦相手の候補**: 過去に記録した相手を対戦回数順にボタンで表示。入力するとひらがな/カタカナを区別せず絞り込み
- **友だち連携**: 「友だち」タブのQRコードかリンクを対戦相手に開いてもらい、届いた友だち申請を「追加」すると連携完了（最初の1回だけ）
  - 以降、友だちとの試合を保存すると相手のアプリにも結果が自動で届く（相手側では勝敗・スコアが反転して記録される）
  - 両方が同じ試合を記録した場合は1試合としてまとめる。自分の記録を削除・修正すると相手側にも反映
  - 記録本体は各端末に保存。受け渡しには無料の中継サービス [ntfy.sh](https://ntfy.sh) を経由する（ntfy.sh の預かりは12時間だが、配達予約を使って約3日間は届くようにし、それでも受け取りの返事が来なければアプリを開いたときに再送）
  - やり取りは端末ごとの鍵で暗号化し、なりすましや改ざんされた内容は受け付けない。メモは送らない
  - **帳簿（改ざん検知）**: 友だちとの試合・削除・奢り・相殺は、署名つき・追記だけの帳簿の1行として送り、相手の端末にも写しが残る。友だちが過去の結果を直すと履歴と通知が出て、帳簿があとから書き換えられると警告する
- **戦績タブ**: 成績と試合の一覧を1ページで表示（期間で絞り込み可）
  - 勝敗・勝率・ゲーム取得率・最終ゲームまでもつれた試合の勝敗、奢りの状況
  - 対戦相手別（勝率・勝敗・最終対戦日。最近対戦した順（既定）・対戦数順・勝率順・名前順。最初は5人まで表示）、大会・練習別
  - 1点ごとに記録した試合のデータ（サーブ時/レシーブ時の得点率など）
  - 試合の一覧（月ごと、検索、タップで詳細・編集・削除）
- **相手ごとの成績**: 相手の名前をタップすると、その相手との勝率・ゲーム取得率・最終ゲームまでもつれた試合の勝敗・連勝/連敗・直近の流れ・対戦履歴を表示
- **奢りメモ**: 試合ごとに「何勝で1奢りか」を選ぶと、相手ごとの奢りを「1.5奢り」のように数える。奢った・奢ってもらったの記録と、お互いの合意による相殺ができる
- **設定**: 自分の名前、画面の明るさ（自動 / ライト / ダーク）、ビットコインへの刻印（OpenTimestamps・オン/オフ）、JSONでのエクスポート/インポート

## 使い方

アプリ: https://tomochi3.github.io/tt_record/

### はじめに

1. 「設定」タブで自分の名前を入れます（友だちのアプリにはこの名前で表示されます）。まだ名前がないときは「友だち」タブの一番上でも入れられます。
2. スマホで開いて「ホーム画面に追加」すると、アプリのように使えます。

### 試合を記録する（記録タブ・デフォルト）

1. 対戦相手を入力します。入力欄の下に過去の相手や友だちがボタンで出るので、タップすれば入力できます。
2. 試合形式（3 / 5 / 7ゲーム）を選び、`3-1` や `2-3` などの結果ボタンを押して「保存」します。保存ボタンは画面の下に固定されているので、スクロールせずに押せます。
3. 日付・大会・練習名・メモは下の「そのほか（任意）」に入れます（日付は今日が入っています）。

### 詳細モード（1点ごと）

1. 記録画面で「詳細（1点ごと）」に切り替え、最初のサーブを選んで「試合開始」。
2. 点を取った側の色（青＝自分、赤＝相手）をタップします。
3. サーブ表示・ゲームポイント・マッチポイント・ジュースは自動で表示され、次のゲームにも自動で進みます。
4. 押し間違えたら「1点戻す」、最初のサーブが逆だったら「先サーブを入替」。
5. 試合中はタブバーを隠してスコアボードを画面いっぱいに表示します。スマホを横向きにしても、点数とボタンが1画面に収まります。
6. 途中でアプリを閉じても続きから再開できます（「一時中断」したときも、戦績タブの赤い帯から）。
7. 試合が終わったら、必要ならメモを書いて「記録を保存」。試合ページで各ゲームのスコア、サーブ時/レシーブ時の得点率、得点の流れが見られます。

試合中は画面が自動で消えないようにしています（Chrome・Edge・Safari 16.4 以降など、対応しているブラウザのみ）。

### 得点板（試合中）

スマホを台の横に置いて、両方の選手に点数を見せるための表示です。

1. 試合中の画面で「📺 得点板にする」を押すと、点数を大きく表示する得点板に切り替わります（対応ブラウザでは全画面になります）。横向きに置くといちばん大きく表示されます。
2. 台の左側にいる選手の点数が左、右側にいる選手の点数が右に出ます。点を取った選手の側をタップします。
3. 名前の横の四角い数字は、取ったゲーム数です。サーブ・ゲームポイント・マッチポイントも表示されます。
4. ゲームが終わるたび、そして最終ゲームでどちらかが5点に達したときに「チェンジエンド」と表示し、左右を自動で入れ替えます。
5. 最初に左右が逆だったときは「⇄ 左右を入替」を押します。押し間違えたら「↶ 1点戻す」（チェンジエンドも元に戻ります）。
6. 「✕ 閉じる」でいつもの表示に戻ります。得点板で使ったかどうかは覚えていて、次の試合も同じ表示で始まります。

### 友だちと連携する（友だちタブ）

対戦相手を友だちに追加しておくと、どちらかが試合を記録するだけで、相手のアプリにも結果が届きます。追加は相手ごとに最初の1回だけです。

追加のしかたは3通りあります。

- **QRコード**: 自分のQRコードを相手のスマホのカメラで読み取ってもらい、「追加する」を押してもらう。
- **リンク**: 「リンクをコピー」または「共有…」で相手に送り、開いて「追加する」を押してもらう。
- **友だちコード**: 相手の「友だちコードをコピー」で送ってもらい、「友だちを追加」の欄に貼り付けて「追加」。名前は相手が承認したときに、相手が設定した名前で自動的に表示されます。英数字20文字だけのIDや、暗号化対応前の古いリンクでは追加できません。

どの方法でも、追加すると相手の画面の上部に「〇〇さんから友だち申請」が表示されます。相手が「追加」を押すと連携完了です（「×」で断ると、その人からの申請は以後表示されません）。申請中に送った結果は相手のアプリで預かられ、追加された時点で反映されます。

連携後は次のように動きます。

- 友だちとの試合を保存すると、相手が次にアプリを開いたときに結果が届きます（相手側では勝敗とスコアが反転して記録されます）。逆も同じです。
- 2人とも同じ試合を記録した場合は、1試合にまとめられます。
- 自分の記録を修正・削除すると、相手側にも反映されます。
- 友だちの名前は、相手が自分で設定した名前で表示されます。相手が名前を変えると、あなたの画面の表示名と過去の試合の相手名も自動で変わります。
- 友だち一覧の「名前」ボタンで、あなたの画面にだけ表示される呼び名に変えられます（相手には伝わりません）。呼び名を付けている間は相手が名前を変えても呼び名のままで、一覧に「本人の名前」が併記されます。空欄にすると相手が設定した名前に戻ります。
- 試合ページの「🔗」の行で、相手に届いたか（送信待ちか）、相手が記録した試合かが分かります。
- 「今すぐ同期」ですぐに確認できます。アプリを開いたときと、開いている間は1分ごとに自動で確認します。

注意点:

- 結果の受け渡しには無料の中継サービス [ntfy.sh](https://ntfy.sh) を使います。ntfy.sh の預かりは12時間ですが、同じ内容を「11時間後〜66時間後に配達」の予約でも預けるので、相手が約3日アプリを開かなくても届きます。それでも相手から受け取りの返事が来なければ、あなたがアプリを開いたときに自動で再送します（3日以上たってから届けたいときは、送った側がアプリを開いてください）。記録本体は各端末にだけ保存されます。
- やり取りの中身は、端末ごとに作られる鍵で暗号化されます。中継サービスや第三者には中身が読めず、友だちになりすました送信や改ざんされた内容は受け付けません（友だち申請の名前だけは暗号化前に送られます）。
- メモは相手に送られません。
- 知らない人からの申請は「追加」を押さない限り友だちになりません。すでにいる友だちと同じ名前の申請には「別の人です」と注意が出ます。
- iPhoneでホーム画面に追加したアプリは、Safariとデータが別になります。カメラでQRコードを読んでSafariで開いた場合は、そのリンクをアプリの「友だち」タブの「友だちを追加」に貼り付けてください。

### 成績を見る

戦績タブに、成績と試合の一覧を1ページでまとめて表示します。上の期間（全期間 / 今年 / 直近90日 / 直近30日）で、ページ全体を絞り込めます。

- **成績**: 勝敗、勝率、ゲーム取得率、最終ゲームまでもつれた試合の勝敗。
- **対戦相手別**: 最近対戦した相手から順に、勝率・勝敗・最終対戦日が並びます（右上で対戦数順・勝率順・名前順に切り替え）。最初は5人まで表示し、「ほか○人を表示」で全員を出せます。
- **試合**: ページの下に月ごとの一覧と検索があります。試合をタップすると詳細の確認・編集・削除ができます。
- 試合の削除・試合の破棄・友だちの解除は確認画面を出さずにすぐ行い、直後のポップアップの「元に戻す」で取り消せます。
- **相手ごとの成績**: 戦績タブの「対戦相手別」の行、試合ページの「vs 〇〇」、友だち一覧の名前をタップすると、その相手との勝率や対戦履歴が見られます。

### 奢りメモ

「負けた方が勝った方に奢る」約束をしたときに使います。設定は不要で、試合ごとに選べます。

1. 試合を記録するとき、「奢り（何勝で1奢り？）」で なし / 1勝 / 2勝 / 3勝 を選びます。同じ相手との次の試合では、前回と同じものが最初から選ばれています。詳細モードの試合でも選べます。
2. 「N勝で1奢り」の試合は、勝つと相手から 1/N 奢り、負けると相手へ 1/N 奢りがたまります（例: 2勝で1奢りなら1試合 0.5奢り）。
3. たまった奢りは「あなた → 山田さん 1.5奢り」「山田さん → あなた 1奢り」のように、相手ごとに表示されます（保存したときの知らせ、戦績タブ、相手ごとの成績ページ）。
4. 奢ったら、相手ごとの成績ページで「💸 1奢りした」、奢ってもらったら「🍜 1奢ってもらった」を押すと、1奢り分が差し引かれます。押した直後のポップアップ（5秒間）の「元に戻す」で取り消せます。
5. お互いに奢りが残っているときは「⇄ ○奢りずつ相殺」で、少ない方の量だけ両方から差し引けます。
   - 連携中の友だちの場合は「相殺を提案」になり、相手が「合意する」を押したときに両方の端末で相殺されます（相手は「断る」もできます）。
   - 連携していない相手の場合は、相手と話して合意してから押してください。

- 連携中の友だちとの試合は「何勝で1奢り」も相手に届くので、相手の画面でも同じように数えられます。
- 連携中の友だちとの「奢った/奢ってもらった」の記録も帳簿にのって相手に届き、相手の画面の貸し借りにも反映されます。2人が同じ1回をそれぞれ記録しても（同期の前に両方が押しても）、2日以内の同じ量の記録は1回分として数えます。
- 以前の「先に○勝した方が奢り・未/済」のメモは、「済」にしたものが「奢った/奢ってもらった」の記録に移ります。

### 帳簿（改ざんを検知できる記録）

連携中の友だちとのやり取りは、ブロックチェーンの考え方のうち「改ざんされたら必ず分かる」部分だけを使った帳簿に残ります。操作は増えません。

- **追記だけ**: 試合の記録・変更・削除、奢った記録、相殺は、上書きせずに帳簿の新しい行として足します。各行には通し番号と前の行のハッシュが入ります。
- **署名**: 各行は端末ごとの署名用の鍵（取り出し不可）で署名します。1行目は署名用の公開鍵です。
- **写しを持ち合う**: 自分の帳簿の写しは相手の端末に、相手の帳簿の写しは自分の端末に残ります。受け取った側は「どこまで受け取ったか（番号とハッシュ）」を返事に入れるので、両方の端末で照らし合わせられます。

相手の成績ページの「📒 帳簿」で、照合の結果と最近の記録（誰が・いつ・何をしたか。たとえば「10/15の試合を変更（結果 2-3 → 3-2）」）を確認できます。友だちが過去の試合を直したり消したりすると、すぐ反映したうえで通知します。

次のようなときは警告を出し、戦績タブの上にも帯を出します（「確認した」で消えます）。

- 相手の帳簿の同じ番号に、前に届いたのと違う内容が届いた（あとから書き換えた証拠として、署名つきの2つの行を保存します）
- 前の行とつながらない行や、署名が正しくない行が届いた（反映しません）
- 相手の端末にある自分の帳簿の写しが、自分の帳簿と食い違っている
- 相手が帳簿をはじめから作り直した（友だちの登録し直しなど。以前の行は残します）

#### ビットコインへの刻印（設定タブ・初期はオフ）

オンにすると、すべての帳簿の「最後の番号と先頭のハッシュ」をまとめた元データのハッシュ値を、1日1回まで OpenTimestamps の刻印サーバー（2か所）に送ります。数時間後にビットコインのブロックに入り、「その日時に帳簿がその状態だった」ことを誰もあとから覆せなくなります。費用はかからず、記録の中身は送りません。設定タブの「証明ファイル（.ots）」と「元データ（.json）」を [opentimestamps.org](https://opentimestamps.org) の Verify に入れると確認できます。

### バックアップ・機種変更（設定タブ）

記録はそのスマホのブラウザの中にだけ保存されます。アプリは起動時に、ブラウザへ「保存データを自動で消さない」よう頼みます（Chrome・Edge・Safari。確認画面は出ません）。iPhone の Safari では7日間開かないと消えることがあるため、ホーム画面に追加して使ってください。設定タブの「データ」に、この端末の状態が表示されます。機種変更の前に「エクスポート」でファイルに保存し、新しいスマホで「インポート」してください（友だち一覧も含まれます）。

## 開発

```sh
npm start        # http://localhost:8000 で起動（python3 の簡易サーバー）
npm test         # スコア計算ロジックのテスト
```

`index.html` をそのまま開いても動きます。

## GitHub Pages で公開

`main` に push すると、GitHub Actions（`.github/workflows/pages.yml`）がテストを実行してから GitHub Pages にデプロイします。

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
公開URLは `https://<ユーザー名>.github.io/tt_record/` です。スマホで開いて「ホーム画面に追加」するとアプリのように使えます。

記録はブラウザごとに保存されるため、端末を変えるときは設定画面のエクスポート/インポートを使ってください。

## セキュリティ

- `index.html` の Content-Security-Policy で、同じサイト以外のスクリプトの実行と、ntfy.sh・OpenTimestamps の刻印サーバー以外への通信を禁止しています（`innerHTML` を使うため、万一の混入対策）。刻印サーバーへは設定でオンにしたときだけ通信します。
- インポートしたファイルや端末の保存データは、読み込むたびに1件ずつ検証してから使います。
- 他のサイトに埋め込まれた状態では画面を出しません（透明に重ねてボタンを押させる攻撃の対策）。
- 受け取った名前からは見えない文字や文字の向きを変える制御文字を取り除き、既存の友だちと見分けがつかない名前を作れないようにしています。壊れた公開鍵の友だち申請は表示しません。
- 同じ端末で複数のタブを開いていても、他のタブで保存した内容を読み込み直すので記録は上書きされません。
- デプロイに使う GitHub Actions は、タグではなくコミットのハッシュで固定しています（タグが書き換えられても別のコードが動かないように）。更新するときは新しいリリースのハッシュに置き換えます。
- 暗号用・署名用の秘密鍵は、ブラウザの中で使えるだけで中身を読み出せない「取り出し不可」の鍵として IndexedDB に保存しています。エクスポートしたファイルにも鍵やIDは含まれません（帳簿もエクスポートには含めません）。
- `tomochi3.github.io` 配下の他の GitHub Pages サイトとはブラウザの保存領域が共有されます。このアカウントで信頼できないコードを含むサイトを公開しないでください（独自ドメインにすると分離できます）。

## 構成

- `index.html` / `css/style.css` — 画面
- `js/scoring.js` — スコア計算（ゲーム判定・サーブ順・集計）。DOMに依存しない純粋関数
- `js/treat.js` — 奢りメモの集計（1勝ごとに 1/N 奢り、奢った記録・相殺の差し引き）。DOMに依存しない純粋関数
- `js/ledger.js` — 帳簿（キー順をそろえた JSON・ハッシュ・ECDSA 署名・行の位置の判定）と OpenTimestamps の .ots 形式。DOMに依存しない純粋関数
- `js/link.js` — 友だち連携のメッセージ形式・検証・暗号化（Web Crypto: ECDH P-256 + AES-GCM）・相手視点への変換・保存データの検証
- `js/theme.js` — 画面表示前にテーマを反映（CSPのためインラインにしない）
- `js/vendor/qrcode.js` — QRコード生成（[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)、MIT）
- `js/app.js` — 画面描画と操作、データ保存
- `tests/` — `node --test` で動くテスト
